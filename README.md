# algal-lab

Reproducible research environments built on [ALGAL](https://github.com/hraness/algal).

The first laboratory studies how network structure affects resilience to failure.
Researchers propose bounded experiments, record predictions before measurement,
retain useful competing designs, and evaluate a frozen portfolio on held-out
conditions. ALGAL supplies typed execution and replayable receipts; the lab owns
instruments, experimental protocols, and scientific interpretation.

This repository is being bootstrapped. The first implementation will include a
credential-free deterministic study, an optional model executor, immutable evidence,
offline verification, tests, and a documented research boundary. Valhalla is outside
this first version.
